iotsploit-usb · Architecture Proposal

Linux / Raspberry Pi 5 Ethernet SCPI Server

A native Linux SCPI-over-Ethernet example server (examples/linux-pi5/) modeled after examples/esp32s3/ and examples/can/. Reuses the existing usbscpi core and usbscpi_socket_glue TCP transport so iotsploit-host can discover and control a Raspberry Pi 5 over Ethernet with zero host protocol changes.

Control Plane: Raw SCPI / TCP :5025 Reuses: usbscpi + usbscpi_socket_glue Pi 5 GPIO: RP1 /dev/gpiochip* (cdev v2 ioctl) Optional Data Plane: TCP :5026 Zero External Dependencies (C99 + Linux UAPI)

1. System Architecture Diagram

usbscpi_socket_glue
glue/usbscpi_socket.c & glue/usbscpi_socket.h

Existing BSD-socket SCPI transport glue. Listens on the configured bind address and TCP port (default 5025), accepts one client session at a time, feeds incoming bytes to usbscpi_on_rx(), and writes replies inline via usbscpi_socket_tx().

  • Calls usbscpi_clear() on every disconnect so a dropped client cannot poison the next session.
  • Requires an explicit bind_addr so exposing 0.0.0.0 on Ethernet is always an intentional decision.
  • Already builds cleanly on Linux with -DUSBSCPI_BUILD_SOCKET_GLUE=ON.

2. End-to-End Request / Response Flow

Synchronous inline reply path over TCP :5025 (no polling or USBTMC MAV handshake)

5. Raspberry Pi 5 Design & Deployment Notes

Zero external library dependencies; safe permissions & host-side testability

RP1 GPIO Chip Discovery (No libgpiod Mismatch)

Raspberry Pi 5 routes the 40-pin header through the RP1 southbridge rather than BCM2835 MMIO. Using Linux kernel GPIO cdev v2 ioctls directly avoids libgpiod v1 vs v2 distro mismatches.

  • Scan /dev/gpiochip* via GPIO_GET_CHIPINFO_IOCTL and select the chip whose label matches pinctrl-rp1 (handles both gpiochip4 and gpiochip0 across Pi 5 kernels).
  • Support --gpiochip /dev/gpiochipX override for other Linux SBCs or kernel gpio-sim testing.
  • Maintain a fixed-size line table (int line_fd[32]) and close all fds cleanly on SIGINT/SIGTERM.

Build, Run & Least-Privilege Deployment

Built conditionally under if(CMAKE_SYSTEM_NAME STREQUAL "Linux") in CMakeLists.txt, following the exact pattern of examples/can/. 

# Build on Pi 5 (or cross-compile for aarch64)
cmake -S . -B build -DUSBSCPI_BUILD_SOCKET_GLUE=ON
cmake --build build --target usbscpi_linux_pi5

# Run bound to Ethernet interface (member of 'gpio' group; no root)
./build/examples/linux-pi5/usbscpi_linux_pi5 --bind 0.0.0.0 --port 5025

# Host control via iotsploit-host
iotsploit-host --tcp 192.168.1.50:5025 query "*IDN?"
iotsploit-host --tcp 192.168.1.50:5025 cmd   "GPIO 17,1"
iotsploit-host --tcp 192.168.1.50:5025 query "SYST:TEMP?"
